metacleaner

A local, offline metadata cleaner and AI-tag remover for images, text/Markdown, HTML, and Office documents — written in Rust. No network calls, no upload: everything runs on your machine.

Install via apt Source on GitHub

Install (Debian / Ubuntu)

sudo install -m 0755 -d /etc/apt/keyrings
curl -fsSL https://siddhantbhattarai.github.io/metacleaner/pubkey.gpg \
  | sudo tee /etc/apt/keyrings/metacleaner.asc > /dev/null

echo "deb [signed-by=/etc/apt/keyrings/metacleaner.asc] https://siddhantbhattarai.github.io/metacleaner stable main" \
  | sudo tee /etc/apt/sources.list.d/metacleaner.list

sudo apt update
sudo apt install metacleaner

This adds a dedicated apt source signed with a repo-specific GPG key (not a global apt-key entry) — standard practice for third-party apt repositories.

What it does

  • Images (JPEG/PNG/WebP/BMP/GIF/TIFF) — strips EXIF, GPS, XMP, IPTC, C2PA content credentials, and AI-generator signatures (Stable Diffusion, DALL-E, Midjourney, Firefly); optional real AI super-resolution upscaling.
  • Text / Markdown — strips invisible-Unicode steganography (zero-width chars, bidi overrides, Unicode Tag block smuggling) and AI-identifying frontmatter keys.
  • HTML — strips identifying <meta> tags (generator, author) and non-conditional comments.
  • Office documents (DOCX/XLSX/PPTX) — strips author, company, and tracking properties; document content untouched.
  • metaclean serve runs a local, drag-and-drop web UI at 127.0.0.1 — loopback only, no authentication, nothing leaves your machine.

Usage

metaclean inspect photo.jpg              # report what's present, read-only
metaclean clean photo.jpg                # strip it, writes photo-clean.jpg
metaclean clean-text notes.md page.html  # invisible chars + frontmatter/meta
metaclean clean-doc report.docx          # Office document metadata
metaclean serve                          # local drag-and-drop web UI
